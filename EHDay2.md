## Linux Permission Groups

Every file and directory in Linux has three categories of users that permissions can be assigned to.

| Symbol | Category | Description |
| :----: | -------- | ----------- |
| `u` | User (Owner) | The owner of the file or directory. |
| `g` | Group | Users who belong to the file's assigned group. |
| `o` | Others | Everyone else on the system who is neither the owner nor a member of the group. |

---

## Linux Permission Types

Each user category can be granted three different permissions.

| Symbol | Permission | Files | Directories |
| :----: | ---------- | ----- | ----------- |
| `r` | Read | View the contents of a file. | List the files inside a directory. |
| `w` | Write | Modify or delete a file. | Create, rename, or delete files inside the directory. |
| `x` | Execute | Run the file as a program or script. | Enter (traverse) the directory. |
